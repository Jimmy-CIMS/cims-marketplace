# Weird Prompt Oracle

Create an unusual but usable creative prompt.

## Workflow

1. Choose a domain: writing, drawing, game, worldbuilding, product, or custom.
2. Combine at least two unlike ideas from `references/prompt_tables.md`.
3. Make the prompt specific enough to start immediately.
4. Include one constraint if the user wants a challenge.
5. Avoid pure nonsense; the prompt should imply tension or possibility.

## Output shape

Return one strong prompt by default. For multiple prompts, use a numbered list.
