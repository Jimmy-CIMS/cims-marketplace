# Weird Prompt Ingredients

## Places

- Rain-only bank
- Museum of unfinished apologies
- Subway station under a forest
- Library that checks out memories
- Hotel for obsolete gods

## Objects

- Compass that points to debts
- Candle that burns backward
- Key made of weather
- Suitcase full of borrowed voices
- Receipt for a future mistake

## Constraints

- Include no proper nouns.
- The ending must be kind.
- The main character cannot speak.
- The danger is bureaucratic.
- Make the object useful but embarrassing.
