# Daily Buff Debuff

Create a playful status card for the user's day.

## Workflow

1. Use `references/status_tables.md` for buff and debuff ideas.
2. Include one buff, one debuff, one trigger, and one small action.
3. Keep effects metaphorical and light.
4. Avoid diagnosing mood, health, or personality.
5. If the user gives context, adapt the status to it.

## Output shape

```text
Status:
Buff:
Debuff:
Trigger:
Tiny Action:
```
