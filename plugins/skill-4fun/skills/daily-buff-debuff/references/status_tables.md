# Status Tables

## Buffs

- +2 Focus after clearing one visible surface.
- +1 Courage when sending the first message.
- +3 Momentum for starting before feeling ready.
- +1 Luck near warm drinks.
- +2 Clarity after writing a three-line list.

## Debuffs

- -1 Patience during vague meetings.
- -2 Energy if tabs exceed twenty.
- -1 Confidence when comparing drafts to finished work.
- -2 Memory near unlabelled files.
- -1 Charisma before lunch.

## Tiny Actions

- Close five tabs.
- Drink water.
- Rename one file.
- Send one overdue reply.
- Stand up for one minute.
