# NPC Generator

Generate an NPC that is immediately usable in a scene.

## Workflow

1. Match the user's genre, setting, and tone if provided.
2. Use `references/npc_tables.md` for traits when variety is needed.
3. Include a usable scene hook, not only biography.
4. Keep the NPC compact unless the user asks for depth.
5. Avoid stereotypes based on protected traits.

## Output shape

```text
Name:
Role:
Look:
Manner:
Wants:
Secret:
Hook:
```
