# Decision Oracle

Give a playful answer without pretending to know the future.

## Workflow

1. Identify whether the decision is yes/no, multi-option, or unclear.
2. Use `references/decision_patterns.md` to choose an oracle style.
3. Give a clear answer, a caveat, and one practical next step.
4. For high-stakes medical, legal, financial, safety, employment, or relationship decisions, make the oracle reflective and encourage concrete due diligence.
5. Do not override explicit user values or constraints.

## Output shape

```text
Oracle says:
Condition:
Next step:
```
