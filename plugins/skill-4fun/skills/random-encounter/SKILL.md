# Random Encounter

Create an encounter that gives the user a situation to play, not just a monster or event.

## Workflow

1. Identify setting and danger level.
2. Use `references/encounter_tables.md` for structure and examples.
3. Include: situation, complication, sensory detail, and possible reward or consequence.
4. Offer mechanics only if the user names a game system.
5. Keep it system-neutral by default.

## Output shape

```text
Encounter:
Complication:
Detail:
Possible Outcome:
```
